P3 ¿Cómo configuraste el Agente Self-Hosted y los Secretos Protegidos?
▶
Tu respuesta clave: "Configuramos el agente autoalojado local mayro-local-agent (v4.274.1) en el Pool Default de nuestra organización DevOps-UMG-Mayro en Azure DevOps. Para cumplir la política de cero secretos expuestos, creamos el Variable Group incident-hub-secrets en Azure Pipelines Library con variables cifradas (candado 🔒: DB_PASSWORD y API_AUTH_TOKEN). El pipeline Build #12 completó con éxito la compilación, pruebas y publicación del artefacto incident-hub-drop."
P4 ¿Cuáles fueron sus Deudas Técnicas y cómo las resolvieron?
▶
Tu respuesta clave: "Documentamos 5 deudas técnicas reales en docs/deuda_tecnica.md y resolvimos 2 de forma medible en la Semana 2:

1. DT-1 (Sanitización y Seguridad XSS - AB#27): Se creó securityMiddleware.js para limpiar etiquetas maliciosas antes de persistir incidentes (PR #1 en w2).
2. DT-2 (Manejo Centralizado de Errores HTTP - AB#21): Se implementó errorHandler.js para uniformar las respuestas JSON ante excepciones (PR #2 en w2)."
P5 ¿Cómo resuelve la Web el problema de las llamadas y WhatsApp dispersos?
▶
Tu respuesta clave: "Sustituye la informalidad con un portal centralizado:

• Formulario Formal: Se reemplazan mensajes ambiguos de chat por un ticket con título, descripción, prioridad, categoría y solicitante.
• Trazabilidad y Asignación: Cada ticket tiene un técnico responsable y pasa por el ciclo NUEVO → ASIGNADO → EN_PROCESO → RESUELTO → CERRADO.
• Auditoría: Se guarda un timeline de quién cambió el estado, a qué hora y con qué comentarios técnicos.
• Dashboard de Métricas: KPIs en vivo con casos críticos y distribución de carga por técnico."
